# Security Policy

## Supported versions

The project currently supports the latest main branch and the most recent published VS Code extension release.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, contact the maintainer directly or open a private security advisory through the repository if that feature is enabled.

Please include:

- a description of the issue
- steps to reproduce it
- the affected version
- any suggested remediation

We will review and respond as quickly as possible.
