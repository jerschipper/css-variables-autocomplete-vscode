# Contributing

Contributions are welcome.

## Development

```sh
npm install
npm run compile
npm test
```

## Workflow

1. Open or create an issue for the change you want to make.
2. Fork the repository and create a feature branch.
3. Keep the scope focused and include tests where appropriate.
4. Run the validation commands before opening a pull request.
5. Submit a pull request with a clear summary of the change.

## Pull requests

Please keep pull requests small and easy to review. Include:

- a brief description of the problem and fix
- relevant screenshots or examples when helpful
- confirmation that validation scripts passed
